# RAG 知识库

审查基于团队的上下文。引擎对团队知识切块、嵌入、检索，让 Agent 引用规范、手册与历史，而不是凭空猜测。

## 流水线

```
团队文档（规范 / 手册 / 视频）
  → 切块
  → 嵌入（走模型网关）
  → 存入 pgvector
  → 审查时检索 → 注入 Agent 上下文
```

## 检索

- **混合检索** —— 向量相似度 + BM25 关键词
- **重排** —— Reranker 在注入前精排候选
- **闸门** —— 相关性闸门决定是否使用检索上下文

## 配置

```yaml
review:
  rag:
    enabled: true
    chunk-size: 512
    top-k: 4
```

## 改善什么

- 安全审查可以引用团队自己的安全规范
- 架构审查可以引用分层约定文档
- 相似的历史发现成为新审查的可检索上下文

## 数据存储

向量嵌入存 PostgreSQL + pgvector。若嵌入维度与既有索引不匹配，向量库自动重建——LangChain4j 集成的文档化行为。
