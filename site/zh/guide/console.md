# 管理控制台

Vue 3 Web 控制台（`code-review-console`，端口 8081）作为引擎前端，提供团队管理、技能、知识与审查运维。

## 技能市场

精选技能包（规则集、Agent 提示词、知识模板）可按团队启用。技能是版本化 YAML 包——引擎原生消费的格式。

## 团队知识库

按团队上传的规范、手册、视频会切块并索引进 RAG 存储，让审查基于团队文档展开。

## 自定义 Agent

团队管理员通过控制台定义业务专属审查 Agent——名称、系统提示词、规则、模型。它们作为并行审查者加入流水线。每个提示词存储前都会过注入预检。

## 审查运维

- 浏览与回放审查轨迹
- 监控质量趋势（反馈、驳回、返工）
- 管理工作流项（改派、异常、抽检）

## 架构

控制台是薄代理：调用引擎的管理 API，从自身静态资源伺服 Vue 构建产物。前端改动以 `npm run build` 产物落入 Spring Boot 静态目录。
