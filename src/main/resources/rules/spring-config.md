# Spring 配置审查要点

- 明文密钥：配置里出现密码 / token / AK 一律报 BLOCKER，要求改环境变量或密钥管理。
- 默认值方向：安全相关的开关默认值必须是「安全的那一侧」（如鉴权默认开启）。
- 环境变量占位符缺失默认值：`${X}` 无默认值时，缺环境变量会启动失败——要么给默认值，要么在文档里写明必填。
- 新增配置项：是否有对应的 `@ConfigurationProperties` 或 `@Value` 消费方？没人读的配置是死配置。
- profile 冲突：`application-dev.yml` 与主配置同名键的覆盖关系是否符合预期。
- 端口 / 超时 / 连接池：数值变更是否与上下游协商过（单点调大常导致下游被打挂）。
