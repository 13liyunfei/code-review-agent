# 安全相关代码审查要点

- 硬编码密钥 / 口令：任何形式的字面量凭据都是 BLOCKER。
- 加密算法：MD5 / SHA1 / DES 用于口令或完整性校验一律要求替换；口令必须加盐慢哈希。
- 随机数：安全场景必须用 `SecureRandom`，`Random` 可预测。
- 日志泄露：把 token、密码、身份证、手机号原样打进日志。
- 命令执行 / 反序列化：`Runtime.exec`、`ObjectInputStream` 的输入是否来自不可信来源。
- 路径拼接：用户可控路径未规范化会目录穿越。
- 比较：口令 / token 比较是否用了恒定时间比较，防时序侧信道。
