# 容器构建与编排审查要点

- 基础镜像：使用浮动 tag（`latest`）会导致构建不可复现，要求固定版本或 digest。
- 以 root 运行：未指定 `USER` 时容器内是 root，要求非特权用户。
- 构建上下文：`COPY . .` 未配 `.dockerignore` 会把 `.env` / `.git` 一起打进镜像。
- 多阶段构建：把构建工具链带进运行时镜像，镜像体积与攻击面都会变大。
- 健康检查缺失：编排层无法判断实例是否真的可用。
- 明文环境变量：compose 里直接写密码（应走 secret / 外部注入）。
- 层缓存失效：把易变文件放在稳定依赖之前，每次全量重装依赖。
