# MyBatis Mapper XML 审查要点

- 动态 SQL 拼接：`${}` 一律视为注入风险；能改 `#{}` 就必须改，改不了的要有白名单校验。
- `resultMap` 与实体字段：新增字段后核对 `resultMap`，避免「字段加了查不出」。
- 查询条件漏 `tenant_id` / `deleted_at`：多租户与软删项目里这是数据越权，属 BLOCKER。
- 批量语句（`<foreach>`）未限制集合大小：一次塞进上万条会打爆数据库，要求分批。
- `LIKE` 直接拼 `%`：注意 `%` 与 `_` 未转义时会全表扫。
- `select *`：列变更后语义漂移，建议显式列名。
