# CI/CD 流水线审查要点

- 密钥注入：流水线里 echo 或在日志里展开 secret 会永久留痕。
- 权限：`permissions` 未收紧（如 `write-all`）时被注入的步骤可改仓库。
- 第三方 Action / 镜像未固定版本：`@master` 可被上游改写，供应链风险。
- 触发条件：`pull_request_target` 配 `checkout` PR 代码等于把密钥交给外部 PR。
- 缓存键：缓存 key 不含锁文件哈希时，依赖更新后仍用旧缓存。
- 失败即停：步骤间未用 `set -e` / `needs` 时，前一步失败后续照跑，产出「假绿」。
- 制品与日志留存期：合规要求下的留存策略是否被改短。
